# Damigotchi Juego - Razas oficiales y selección inicial

Incluye:
- Pantalla inicial para elegir raza Damigotchi.
- Nombre personalizado de la mascota.
- Razas oficiales: Naturaleza, Fuego, Agua, Energía, Sueño, Estrella, Zorrito y Pantera.
- Historia y frase de cada raza en la selección.
- Botón 🧬 en el inicio para cambiar de Damigotchi si ya existe uno guardado.
- Mantiene estrellas, ropa, tienda, cartas, globos, castor PRO, dibujo, colorear, galería y vida suave.

## Ejecutar

```bash
npm install
npm run dev
```
